# Security policy

Horadric Odds is a static website hosted on GitHub Pages. It has no accounts or passwords, and no server of its own. Everything you enter, including save files you open, stays in your browser. Shared builds in the community gallery are stored through claude.ai.

## Reporting a problem

If you find a security problem, please **don't open a public issue**. Email **HoradricOdds@hotmail.com** with:

- what the problem is and where (page, tab or file),
- steps to reproduce it,
- what someone could do with it.

You'll get a reply as soon as possible, usually within a few days. Please give us reasonable time to fix it before telling anyone else. We'll credit you in the changelog if you'd like.

## What counts

For example:

- a way to run someone else's code in a visitor's browser, for example through a shared build code, a build name, a pasted code or a save file,
- a save file or build code that can make the save editor produce a file that harms the game or your computer,
- a way to read, change or delete other people's shared builds.

Bugs that only affect your own character (for example, an edited save that the game rejects) are normal bugs; please use the bug report form.

## Supported version

Only the live site at [horadricodds.github.io](https://horadricodds.github.io/) is supported. Fixes go there straight away.
