Horadric Odds Gear-tab update

Upload these files to the root of the GitHub Pages repository:
- index.html (replace the current file)
- images/items/ (add this folder and all of its WebP files)

The Gear tab shows equipped items using their inventory footprint. Main character slots use 28 px per inventory cell; charms, weapon swap, and mercenary cards use 20 px per cell. A 2x4 shield is 56x112 px in the main equipment view.

The Gear tab includes an item-art credit and states that Horadric Odds does not own or claim rights to the artwork. Keep that notice visible if you publish the image files.
