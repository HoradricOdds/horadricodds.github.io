Horadric Odds Gear-tab update

Copy these into the root of the GitHub Pages repository:
- index.html (replace the current file)
- images/ (merge this folder into the repository; it contains item art and the inventory background)

The Gear tab uses the D2R inventory panel background. Items display in their matching equipment slots using their base item inventory footprint. Charms are packed into the 10x4 backpack grid without overlap. Main equipment art scales to the background grid; compact weapon-swap and mercenary cards use a smaller scale.

Item artwork source: https://lootcube.net/en/base-items
Inventory background source: https://i.dimentio.dev/d2r/ui/panel/inventory/background.png
